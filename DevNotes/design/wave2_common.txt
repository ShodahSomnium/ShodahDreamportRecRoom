What "done" means for your place/game:
- Registered through its RrRegistry partial hook (ARCHITECTURE §11) with title, subtitle, description, category, min/max
  players, cover/icon sprite names (SP\research\rr_watch_ui.md lists the artwork per activity), music.
- Built at its origin by Build() (coroutine, yield between chunks) from Rec Room's own prefabs where the bundles have them
  (use RrSpawnOptions.Scenery() for furniture/architecture that must not move) plus RrBuild/RrLook geometry following the
  research doc's rebuild plan and Rec Room's real layout; lit so it looks like Rec Room (bright, soft, colourful).
- Plays like Rec Room: the rules, timings and numbers from the research doc (read from Rec Room's own configs where
  measured), Rec Room's sounds, music, announcer lines and effects, match flow via RrGameRoom (or RrRoom for social rooms).
- Works in desktop screen mode and in VR (RrHand/RrInput; client-owned keys are off limits), offline in the editor (the
  local player is authority) and networked (instance authority = the "fake master"; state in RrNet.Instance custom ints,
  events with type ids >= 64 via RrNet.Send/On, props with RrNetBody, AI in actor blocks) - see somnium_networking.md §5.
- Everything drawn for other players only while they are in the same instance; never touch avatars.
- Verified in the play-mode harness: write SP\harness\scenarios\<activity>_*.json that boots, travels to your activity
  (step {"goto": "<RrActivity name>"}) and takes screenshots from several viewpoints (overview, spawn view, key areas), plus
  test hooks you add (static methods callable with {"call": "Namespace.Type.Method"}) to exercise gameplay (start a match,
  fire, score). Run with: bash SP/harness/run.sh <scenario.json> (one Unity at a time, it waits for a lock; ~20-40 s per
  run). LOOK at every PNG with the Read tool and iterate until it looks like the Rec Room room described in the research
  doc; fix what looks wrong. Keep runs purposeful (each costs time).
- Compiles: bash SP/compilecheck/build.sh project --editor -> 0 errors, guard "all N ... proven". Other agents edit other
  folders at the same time: if an error is in someone else's file, wait a minute and re-run; never edit it.
- New files get .meta files: bash SP/tools/metas.sh
- Ownership: edit ONLY your own folder (given below). Foundation bugs: you may fix a clear bug in Core/, Rr/, Player/,
  Interact/, Net/, Rooms/, Watch/, Games/Shared/ minimally when it blocks you (say exactly what in your result); for missing
  features write a local helper in your folder and list the request.
- Log key facts once with RrLog; no per-frame logs.
