# Material descriptions for the Rec Room Dreamport layouts (2026-11-22)

Tool: `DevNotes/tools/apkscene` command `matdesc` (files `MatRun.cs`, `MatTex.cs`, `MatDesc.cs`; debug views `MatDbg.cs`).
It reads the user's Android build (data only) and writes names and numbers into the layouts. No pixels, meshes or shader
code are copied anywhere; textures are decoded in memory only to measure mean colours.

- 80 of the 81 `Layouts/<Scene>.bytes` were rewritten. **RecCenter_Builtin.bytes was not written**: the coordinator is
  replacing it with a new conversion and runs the command on it (its row below is from a dry run of the old file).
- Originals: `DevNotes/refdata/layouts_backup_2026-11-22/` (81 files + `_md5_originals.txt`).
- Every row of this report: `DevNotes/refdata/matdesc_2026-11-22.tsv` (kind K / H / P, one row per record).
- Verification: `matcheck` (C#) and an independent shell check (`gzip -dc`, drop `K ` lines, strip the trailing
  ` gcol=` / ` avg= itex=` keys, `cmp` with the original): 81/81 identical, every file passes `gzip -t`, the K lines sit
  right after the last T line, one K per '?' T entry. `.meta` files untouched.

## Layout -> Android level

Every layout is a scene of one Android level; the level was taken from the `# source: ... levelN = <scene path>` line
of `refdata/apk/<Scene>.rrsk` (all 81 have one; the gtscene / dressed / paintball variants were converted from the same
level). The BuildSettings scene path confirms each (e.g. Crimson_Bog = level56 `Quest_Goblin2_Bog.unity`,
Crescendo_Park = level86 `Quest_Dracula1_Park.unity`, Maker_Park = level75 `Park.unity`, Maker_PerformanceHall = level73).
No layout was unmappable. Every '?' material was found in its level (450/450).

## Records written

```
K <t> col=r,g,b,a [avg=r,g,b] [tex=<install Texture2D>] [tile=sx,sy] [toff=ox,oy] mode=opaque|cutout|fade|add
      [cut=x] [opa=x] [amask=1] [vc=1] [emit=r,g,b] [glow=p] shader=<android shader>
K <t> col=r,g,b,a mode=none hide=1 shader=<android shader>          (a shader that draws nothing)
K <t> col=0.62,0.62,0.64,1 miss=1                                   (material not found: did not occur)
H grid ... <unchanged> gcol=r,g,b                                   (appended last)
G platemat <unchanged> avg=r,g,b itex=0|1                           (appended last; avg left out if it cannot be measured: did not occur)
```
Numbers have up to 4 decimals, names are RRSK-encoded (%20 for spaces, e.g. `shader=Shader%20Forge/Particles/PaperFlame`).
Key order is fixed as above. A K record is written for every '?' T entry (also `?none`).

| key | meaning |
| --- | --- |
| col | the colour the shader reads, as stored (sRGB floats): the first of _BaseColor, _Color, _MainColor, _TintColor that the material has AND the GLES3 program reads (else the first the material has; else 1,1,1,1). 433 x _BaseColor, 16 x _Color, 1 x _TintColor. |
| avg | flat colour to draw without a texture = the main texture's top-mip mean in sRGB (stored) space times col (clamped 0..1). Opaque: all texels. cutout: only texels with alpha >= cut. fade/add: alpha-weighted. With amask: the tint is applied per texel as lerp(1, col, a). Vertex colours are NOT in avg. Splat-blend ground shaders (AG/TerrainSplats): control-map-weighted mean of the splat textures x their _SplatN_Tint. Omitted when the shader samples no main texture. |
| tex | the main texture's name, only when a Texture2D of exactly that name is in `rrtoolidx/objects.tsv` |
| tile / toff | _BaseMap/_MainTex scale when not 1,1 / offset when not 0,0 (toff is an extra key; 54 lines, the light-shaft gradients use 0.09,0) |
| mode | from the forward pass's blend state (property-bound factors resolved through the material's floats): One/Zero = opaque, or cutout when the alpha test is on; dst One = add; SrcAlpha or One / OneMinusSrcAlpha = fade (two multiply-blend platemat materials are also written as fade). `none` = hide=1. |
| cut | _Cutoff, written when the alpha test is on (also on a fade material that clips) |
| opa | fade/add only: mean texture alpha x col.a = the average opacity / additive strength (extra key; written when < 1) |
| amask | Rec Room's AG shaders compute albedo = lerp(tex, tex * tint, tex.a) with tint = vertex colour x col: the tint (and vertex colour) only applies where the texture alpha is 1. Written when the GLSL has that pattern, the texture's mean alpha < 0.98 and the tint matters (col not white or vc=1). |
| vc | the shader multiplies vertex colours (see below) |
| emit | emitted colour (mean): _EmissionColor (x the mean of _EmissionMap when sampled) when the program reads it, plus `_Emission`/`_EmisColor`/`_EmissiveColor` when read (Shader Forge), plus Rec Room's texture glow (below) |
| glow | AG/Standard's texture glow: the program adds tex.rgb x tex.a x _EmissivePower x tint; glow= is _EmissivePower (> 0 and read by the program); its mean is already in emit= |
| hide | AG/DoNotRender: every vertex program is `gl_Position = vec4(0)`; draw nothing (14 entries, InvisibleWall_Nav_Mat and Candle_Emit_Mat) |
| shader | the Android shader's name (m_ParsedForm.m_Name) |
| gcol | H grids whose mat is a guess or '?name' (all 79 such grids got one; the 5 bare `mat=?` grids are collider-only vis=0 and have no material: left alone). Terrain: each layer's diffuse mean, tinted by its TerrainLayer diffuse remap (max - min, applied in linear space; the frontier layers are grey textures tinted this way), weighted by the splat maps' coverage inside the grid's own XZ rectangle (whole map for the far grids). Disc Golf's `<terrain>Collider` grids use the same terrain. Mesh ground: the material's avg (or col); when vc=1 and the mesh has vertex colours, their area-weighted mean over the up-facing triangles of that submesh is put into the tint (as a linear factor, so x Gam(vc) in sRGB) and the avg recomputed with the alpha mask. |
| avg / itex on G platemat | for platemat lines with inst=0 or a tex that is not an install Texture2D (1,672 lines in the 79 written layouts; 329 of them have an install texture, itex=1): the level texture of that name, mean x the line's col, with the same mode / cutout / amask rules as K when the material is found in the level (else plain opaque mean); tex=- -> avg = col. |

## How things were decided (and what is uncertain)

- **GLES3 programs as evidence.** Each Android Shader carries its GLES3 GLSL (LZ4 blob, platform 9). The tool takes the
  forward pass (LIGHTMODE UniversalForward / SRPDefaultUnlit / first non-shadow/depth/meta pass) of the first subshader
  that has GLES3 programs, and the variant(s) matching the material's keywords with the fewest extra keywords, and reads:
  which colour/texture the program uses, `discard` (alpha test), a varying fed from `in_COLOR0` that the fragment reads
  (vertex colours), `_EmissionColor` / `_EmissivePower` use, the alpha-mask lerp, and `gl_Position = 0` (hidden).
  Keyword / queue / RenderType rules are only the fallback (no shader without GLSL remained).
- **Vertex colours (vc=1, 355 of 440 written entries).** Decided from the GLSL: AG/Standard-Opaque, -Transparent, -Emission(-Scroll), -Instanced and -AlphaClip pass
  `in_COLOR0` to the fragment and multiplies it into the tint (`vertexColor.rgb * _BaseColor`), so AG/Standard
  materials are vc=1 even without "VertColor" in the name (AG/Standard-Opaque-Projection and -Decal do not: vc=0); AG/Unlit-Additive(-Soft), AG/Unlit-Transparent and the Shader
  Forge particle shaders multiply too. Nature/Leaf reads vertex colour only for wind bending (vertex stage) -> vc=0.
  The name rule (VertColor / VerColor / VertexColor / Vertcolor in material or shader name) is ORed in. With amask=1
  the vertex colour is masked by texture alpha like col.
- **sRGB.** col / emit are the stored (sRGB) material values; texture means are means of the stored 8-bit values (sRGB
  space), so avg = mean x col is an sRGB-space product (exact under a power-law gamma for linear-space rendering).
  Vertex colours and TerrainLayer remap factors are raw linear factors and are converted (Gam) before multiplying.
- **Texture formats met:** ASTC 4x4 and 8x8 for all main textures (decoder from the earlier sky work), RGBA32 for splat
  maps. An ETC1/ETC2 decoder was added but no measured texture needed it (untested on real data).
- **Leaves / cutout:** avg is the mean of the texels that survive the alpha test (trees come out olive / red / gold
  as expected; the aspen atlases include white-grey trunk texels).
- Two terrain-ish meshes use AG/TerrainSplats (Spillway play area, Drive-In backdrop): handled by the splat rule.
- MerryMidway's far roof grids come out very dark: their vertex colours really are near black on the up-facing
  triangles (1/255 on Static-8), so gcol 0.045 follows the data.
- Not modelled: lighting (lit vs unlit), normal maps, height blending of splats, fresnel/scroll effects.
