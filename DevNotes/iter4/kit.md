## What the kit does (defaults)
Parse on RrMain.Worker -> root at options.Position/Rotation under parent (records keep scene TRS as root-local) ->
load meshes (43) / materials (21, RrMaterials.Fix) / prefabs (1) by exact name via catalog TryFind first (missing = no
warning, listed in result), 24 loads in flight, 60 s timeout (RrTravel gives a room build 90 s) -> renderers merged with CombineMeshes per material x
vertex-attribute mask x 32 m cell (centred on origin), <= 60k verts, UploadMeshData(true), shadows off, probes off;
unreadable / mirrored / >60k / non-triangle -> own renderer -> stand-ins (X) merged per quantised colour (31 steps) x
cell, RrLook.Solid or RrLook.Glass (alpha < 0.99) -> P via RrSpawn.SpawnLoaded(Scenery, StripLights) -> colliders on
layer 23: box/sphere/capsule grouped on one object per rotation (1/1000, max 256), mesh colliders pre-cooked with
Physics.BakeMesh on the worker -> lights: point/spot only, top 8 by intensity x range, shadows off (dir skipped) ->
audio loops through RrSound.Loop (12 max, loudest), one-shots -> "audio" markers -> fog reported only, ambient/sky
reported (ApplyAmbient/ApplySky opt-in, restored on destroy) -> G markers -> one summary log line. 4 ms/frame budget;
stops cleanly (Cancelled, root destroyed) if parent/root dies. Drops X_LOD1..7 when X_LOD0 is in the table.

## Not verified / risks
- Not run in Unity (the project must not be touched now): compile + offline parser test only. Run
  scenarios/scenekit_test.json after install; expected counts are in RrSceneKitTest.Build.
- Physics.BakeMesh on a worker thread is documented thread-safe but unproven in the client; a failure is logged once
  and the colliders cook on assignment. The int overload is obsolete in 6000.3 (pragma'd; present in 6000.3.21).
- Mesh colliders from unreadable install meshes may not cook in a player (rr_runtime_facts says they work).
- Merged meshes: object-space shader effects and per-object data change; no lightmaps (rooms are lit by our lights +
  ambient). Combine=false is the escape hatch.
- Collider rotations are very varied in REF2 (GTact1: 122 distinct among 449), so grouping only gives ~4:1.
- Name lookups take the first catalog entry (containers first) for duplicate names.
- Budget: CombineMeshes of one 60k-vertex batch is one unsplittable step (probably > 4 ms; builds run behind the
  loading card). Lower MaxBatchVertices if the harness shows long steps.
